# ✏️ Draw2Web AI

Draw2Web AI is an AI-powered web development tool that converts hand-drawn UI sketches and wireframes into functional website code.

## 🚀 Features

- ✏️ Draw UI wireframes directly on the canvas
- 🔍 Analyze hand-drawn designs using AI
- 🤖 Generate websites using Gemini AI
- 🌐 Preview the generated website
- 📱 Desktop and mobile preview
- 🧩 Detect UI components from drawings
- 💻 Generate HTML and CSS automatically
- 📋 Copy generated HTML and CSS
- 📥 Download the generated website
- ⚡ Simple and interactive interface

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- Gemini AI API

## 🔄 How It Works

1. Draw a website layout or UI sketch.
2. Click **Analyze Drawing**.
3. AI analyzes the hand-drawn design.
4. Gemini AI generates the website structure and styling.
5. Preview the generated website.
6. View or copy the generated HTML and CSS.
7. Download the generated website.
